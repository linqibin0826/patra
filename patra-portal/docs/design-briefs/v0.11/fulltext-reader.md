# 文献详情页 · 全文阅读 — Design Brief

> v0.11 唯一一份设计简报，同时承担产品定义（本版不单开 [Product]）。设计系统与代码库已 onboard，本简报只交增量。
> 可交互画板：Claude Design 画布「v0.11 全文阅读」<https://claude.ai/artifact/4GKkd2ioquYvJmxP3vXjED>（桌面 1440 + 移动 375，场景用画板的 Tweaks 切换）；快照见 `docs/patra/design/snapshots/2026-10-19-fulltext-reader-hifi.zip`。
> 同版相关：release spec `docs/patra/release-specs/v0.11-fulltext-reader.md`；后端工程 spec `docs/patra/specs/2026-10-19-fulltext-reader-backend-design.md`（接口字段与正文结构以它为准，本简报附录 A 只列设计侧的补充要求）；Linear PAP-83（本简报 + 画板）→ PAP-87（BE 读端点）/ PAP-88（FE 实现）。

**目标**：在 PMC 开放获取子集里的文献，在详情页 `/papers/[id]` 直接读完整正文（章节目录、图、表、公式、参考文献），能下载期刊原版 PDF（PMC 提供了才有）；没有全文的文献，页面说清原因并保留去原文的出口。

**画板素材**：全部取自 PMC 公开桶 `pmc-oa-opendata` 的真实文章，不依赖后端解析器。

## 0. 策略与定位

- **正文放在详情页内，不单开阅读页。** 同一个地址 `/papers/[id]`：题录头 → 摘要 → 关键标识 → 深度数据（折叠）→ **全文** → 参考文献 → 许可与出处。理由：
  1. **从判断到阅读是一条连续的路。** 访客先看题录头和摘要决定读不读，往下滚就进正文。单开阅读页多一跳，返回时又要在两页之间来回，"打开即读"变成"打开再点再读"。
  2. **一篇文献一个地址。** 分享、收藏、引用都指向同一页，不出现"详情页和阅读页哪个是正本"的问题；也不用在阅读页再做一遍题录头和许可署名。
  3. **详情页已经有长文阅读的底子**：吸顶面包屑自带阅读进度条（`read-progress`，跟随整页滚动）、serif 阅读正文样式（`reading-body`）、主栏 + 侧栏的双栏版式。全文接进来，这些直接生效。
  4. **代价是页面变长**，用三件事化解：题录头的主按钮改成「阅读全文」直接跳到正文；桌面侧栏在正文区域变成吸顶目录；移动端面包屑右端多一个「目录」按钮，打开底部目录面板。
  - 不选单开阅读页（如 `/papers/[id]/read`）：它换来的只是"更专注的版面"，而详情页正文区本身就是 36em 行宽的单栏阅读区，侧栏在正文区只剩目录，专注度已经够了。
- **渐进式披露**：
  - **默认层**：题录头、摘要、关键标识（不变）；**全文正文**（章节、段落、图、表、公式）全部展开——正文就是本版的主角，读者滚到这里就是要读。
  - **深数据层**：深度数据折叠区（不变，仍在全文之前，收起时只占几行）；**参考文献**默认只显示前 5 条，「展开全部 N 条」；**长表格**超过 12 行只显示前 10 行，「展开全部 N 行」；**许可与出处**完整信息在文末，正文开头只放一行出处条。
- **只做格式转换，不改写内容**（ND 许可只允许格式转换，release spec 决策 C）。图注、表注、"Figure 1""Table 2"这类标签都保留原文，不翻译、不改写；Patra 自己加的只有界面文字（"全文""目录""展开全部"等）。
- **许可与出处必须可见**（决策 D）：正文开头一行出处条 + 文末「许可与出处」版权页，两处都有许可类型。不使用 PMC 标志。
- **职责边界**（release spec 第 3 节）：不展示补充材料与多媒体（JATS 里 `Supplementary material` 一节整节不渲染，也不给下载）；正文不进检索；不做划词翻译、高亮批注；参考文献只给外链（DOI / PubMed），不跳 Patra 内部详情页；AI 速读卡片保持「即将上线」，不用全文生成；PMC 没提供 PDF 时不显示下载按钮，不自己生成 PDF；在 PMC 免费可读但没有开放许可的文章不展示正文，只给去 PMC 的链接；撤稿文献不展示全文（后端在读端按 PubMed 文献类型或抓取时 PMC 的撤稿标记判定，全文自动下线）。

## 1. 用户与场景

| 用户 | 场景 / 任务 |
|------|-----------|
| 临床医生 | 从首页或检索点开一篇 RCT，看完摘要觉得相关，点「阅读全文」直接读方法和结果，在表格里找关键数字 |
| 科研人员 / 研究生 | 精读：用目录跳到某一节，点正文里的引用看参考文献，再回到刚才读的位置；需要存档时下载原版 PDF |
| 泛读者 | 只看摘要，不往下滚；正文的存在不打扰他（摘要位置、题录头不变） |
| 任何人 | 点开一篇没有开放全文的文献：页面写清楚为什么没有，给出去原文的出口 |

## 2. 要设计的屏 / 流程

只有一屏：文献详情页 `/papers/[id]`，按全文情况分状态（§4）。另有两个随正文出现的浮层：图片放大层、移动端目录面板。

**文字流（有全文）**：首页文献卡「详情」→ `/papers/123` → 题录头点「阅读全文」→ 平滑滚到「全文」区块顶部 → 读 Introduction → 点正文里的引用 `12` → 跳到参考文献第 12 条（参考文献自动展开、该条高亮）→ 点该条后面的「↩ 回到正文」→ 回到刚才那个引用的位置 → 在侧栏目录点「Results」→ 跳到 Results → 点「下载 PDF」→ 浏览器下载 `PMC13583816.pdf`。

**文字流（无全文）**：`/papers/456` → 题录头主按钮仍是「去全文 · DOI ↗」→ 往下滚，在「全文」区块看到「暂无开放全文」和原因 → 点「去全文 · DOI ↗」新标签打开出版方页面。

## 3. 每屏内容与数据 ← 最关键

### 3.1 题录头的操作按钮

| 情况 | 按钮（从左到右） |
|------|----------------|
| 有全文 · 有 PDF | 「阅读全文 ↓」主按钮（锚点跳到 `#fulltext`，不是外链）· 「下载 PDF」次按钮，按钮后跟等宽小字文件大小（`2.5 MB`）· 收藏 |
| 有全文 · 无 PDF | 「阅读全文 ↓」主按钮 · 收藏（**不显示**下载按钮，也不显示禁用态） |
| 无全文 | 与现在一致：「去全文 · DOI ↗」主按钮（外链）· 收藏 |
| 有 PDF 无正文 | 「下载 PDF」主按钮（带文件大小）· 收藏；「去全文 · DOI ↗」放在全文区块的说明面板里 |

- 有全文（以及有 PDF 无正文）时外链出口不消失，降为侧栏操作卡里一行文字链接「在 PMC 查看原文 ↗」，以及文末版权页里的 DOI、PMC 链接。
- 已撤稿的文献在刊头行（文献类型那一行）加一枚 rust 状态胶囊「已撤稿」，用 `status-danger` 圆点 + 文字，不只靠颜色。

### 3.2 桌面侧栏（≥ 980px）

- **无全文 / 有 PDF 无正文**：与现在一致（操作 / AI 速读 / 速览三张卡整体吸顶）；操作卡的按钮按 §3.1 换。
- **有全文**：侧栏不再整体吸顶。操作 / AI 速读 / 速览三张卡跟着页面滚走，下面跟一张**目录卡**，它单独吸顶（`top: 134px`，与现有吸顶偏移一致），从全文区开始一直陪到页底。纯 CSS 就能做到：侧栏撑满网格行高，目录卡 `position: sticky`，不需要按滚动位置切换内容。
- **目录卡**：
  - 卡头：等宽小标「目录」，右侧 `≈ 25 分钟`。
  - 列表：正文的一级章节（JATS `sec` 第一层的标题），当前所在章节的二级标题在它下面展开；末尾固定两项「参考文献」「许可与出处」。
  - 当前章节：文字转 `fg-1`，左侧一道 2px clay-500 指示条（与检索结果行的页边竖线同一语言）；其余 `fg-3`，hover 转 `fg-1`。当前章节由前端用 IntersectionObserver 判定（标题越过吸顶线即算进入）。
  - 卡底：有 PDF 时一个整宽次按钮「下载 PDF · 2.5 MB」；再下一行等宽小字 `CC BY 4.0 · 抓取于 2026-10-18`。
  - 目录项超过卡片可用高度（视口高 − 134px − 底部留白）时，卡内滚动，当前项自动滚进可见区。
- **速览卡**的「原文阅读」：有全文时显示 `≈ 25 分钟`（来自后端阅读时长），无全文时 `—`。

### 3.3 移动端（< 980px）

- 单栏，顺序同桌面主栏；侧栏三张卡仍落在主栏之后（与现在一致），**目录卡不出现在侧栏**。
- **面包屑右端**多一个药丸按钮「目录」（`ListTree` 图标 + 文字，44px 触控高度），只在有全文时出现。点开从底部升起目录面板（Sheet：`bg-scrim` 遮罩、`bg-elevated`、`shadow-lg`、顶部圆角 `radius-xl`、最高 70% 视口），内容同桌面目录卡；点任一项跳转并收起面板；面板底部同样有「下载 PDF」。
- 题录头按钮自动换行；「阅读全文」与「下载 PDF」在 375 宽下并排放得下，收藏换到下一行。

### 3.4 全文区块 `#fulltext`

**区块头**

- 栏目小标：eyebrow「全文」（与「摘要」「关键标识」同一组件 `SectionEyebrow`）。
- 统计行（等宽 `mono-meta`，`fg-3`）：`5,701 词 · ≈ 25 分钟 · 3 图 · 3 表 · 40 篇参考文献`（按后端口径实测的 PMC13583816；画板里仍是旧口径的 6,913 词 / 31 分钟，PAP-88 的夹具期望值以后端为准）。
- **出处条**：上下两道发丝线夹住的一行，左侧许可胶囊（`Pill`，如 `CC BY 4.0`；全文接口 `license` 为 `null` 时写「许可见原文」）；作者手稿（`isManuscript = true`）再跟一枚中性胶囊「作者手稿」；右侧一句：全文接口的 `source` 原样显示（`数据来源：美国国家医学图书馆（NLM）PubMed Central`）+ ` · PMC13583816 · 抓取于 2026-10-18`，行尾链接「许可与出处 ↓」跳到文末版权页。移动端出处条折成两行。

**正文排版**

| 元素 | 呈现 |
|------|------|
| 一级标题（`sec` 第一层） | serif 24px（`text-2xl`）500，`tracking-tight`；上间距 48px、下 16px；JATS 有 `label`（如"2."）就照原样放在标题前 |
| 二级标题 | serif 19px（`text-xl`）500；上 32px、下 12px |
| 三级及以下 | sans 15px 600，`fg-1` |
| 段落 | `reading-body`：serif 17px，行高 1.65，ink-800，行宽 ≤ 36em；段距 1em |
| 正文前导块（顶层 `blocks`） | `<body>` 里第一个章节之前的内容（如 BMJ Open 开头的 "Strengths and limitations" 框），放在出处条之后、第一个一级标题之前；不进目录 |
| 无标题章节（`title` 为空数组） | 章节之后又出现的直接内容：不渲染标题、不进目录，块照常接在上一章节后面 |
| 行内格式 | 斜体、粗体（600，不用 700）、上下标、小型大写照原样；外链用 `link` 色 + `link-draw` |
| 行内公式（`math`） | 段落、表格单元格、标题里都可能出现，渲染规则相同（见「公式」） |
| 交叉引用（`xref`） | 引用、图、表、公式、章节、脚注、文本框（`boxed-text`，跳到 `box` 的 `id`）都是页内锚点；后端对找不到目标或类型不在白名单里的引用只给文本，前端照普通文字显示 |
| 列表 | serif 正文字号，项目符号 ink-400，左缩进 1.25em；有序列表用原文编号 |
| 引文框（`quote`） | serif 正文字号、`fg-2`，左缩进 1.5em，左侧一道 1px `border-strong` 竖线 |
| 文本框（`box`，如 BMJ 的 "What is already known"） | `bg-paper` + `border-default` + `radius-lg`、20px 内边距；标题 sans 13px 600 大写小标，内容照块渲染；带 `id`，可被交叉引用 |
| 代码（`code`，含只有 TeX 的公式） | 等宽 13px、`bg-sunken`、`radius-md`、12px 内边距，`white-space: pre`，盒内横滚；来自 `tex-math` 的块上方加等宽小标「公式 · LaTeX 源码」 |
| 文末附加（`back`：致谢、脚注、附录） | 放在正文之后、参考文献之前，标题同一级标题，正文同段落，字号降一档（serif 15px）；目录里列在「参考文献」之前 |
| 表头单元格（`header = true`） | 在表体里出现时（行标题）用 600 字重，渲染为 `<th scope="row">` |
| 补充材料一节 | 不渲染（职责边界 E），目录里也不出现 |

**引用跳转**

- 正文里的引用照原文样式显示（上标数字 `12`、方括号 `[12]` 或 `(Smith 2020)`，原文是什么就是什么），颜色 `link`（clay-700），不加下划线，hover 出现 `link-draw` 下划线；`aria-label="参考文献 12"`。
- 点击 → 页面滚到参考文献对应条目（`scroll-margin-top` 留出 TopNav + 面包屑 = 101px 再加 16px），参考文献列表若是收起状态先自动展开；目标条目底色用 `accent-tint` 亮起，1.6 秒后淡回（减弱动效时直接常亮到下一次点击）。
- 每条参考文献末尾有「↩ 回到正文」：回到**刚才点击的那个引用**的位置（前端记下来源锚点）；直接打开 `#ref-12` 进来的，回到该文献在正文中第一次被引用的位置；从没被引用过的条目不显示这个链接。
- 正文里指向图、表的交叉引用（"see Figure 2"）同样是页内锚点，跳到对应图表。

**图**

- 图块宽度用满主栏（桌面约 788px，比正文行宽 612px 宽），居中；图片放在 `bg-paper` + `border-subtle` + `radius-lg` + 16px 内边距的托盘里。
- **限高**：图片最高 `min(70vh, 560px)`，按比例缩放、居中（`object-fit: contain`）。竖长的流程图不会一张占满两屏；看细节点开大图。
- 图注在下方：第一行等宽大写小标照原文（`FIGURE 1`）+ serif 15px 500 的图题；下面是图注正文 sans 13px `fg-2`。
- 点击图片 → 放大层：ink-900 · 70% 遮罩 + 8px 背景模糊（与快速检索同一层级语言），图片适配视口，下方图注，右上角关闭按钮（`aria-label="关闭"`），Esc / 点遮罩关闭，左下「在新标签打开原图 ↗」。移动端放大层全屏，图片按原尺寸放在可滚动容器里，用系统双指缩放。
- 加载：后端提供图片宽高时，先按比例占位（纸面微光骨架），图片到了再淡入，不跳动。

**表**

- 表题在表**上方**（期刊惯例）：等宽大写小标 `TABLE 2` + serif 15px 500 表题；表注（`table-wrap-foot`）在表下方，sans 12px `fg-3`。
- 表格放在 `border-default` + `radius-lg` 的盒子里；表头 `bg-sunken`、sans 12px 600 `fg-2`；单元格 sans 13px（`text-sm`，20px 行高）、`tabular-nums`、内边距 8px × 12px，行间 `border-subtle` 发丝线；合并单元格照原表。
- **宽表**：盒子内横向滚动（`overflow-x: auto`），不撑破页面；第一列吸左（`position: sticky; left: 0`，`bg-paper` 打底，右侧一道 `border-default`），滑动时行名始终可见。有横向溢出时右边缘渐隐，移动端表下多一行等宽小字「左右滑动查看完整表格」。
- **长表**：正文行超过 12 行时只显示前 10 行，底部渐隐 + 药丸按钮「展开全部 66 行」；展开后按钮变「收起」放在表尾，收起时页面滚回表题。
- 表格不做页内纵向滚动（避免手机上的嵌套滚动）。

**公式**

- 后端输出 MathML，浏览器原生渲染（release spec 决策 C）。数学字体：`"STIX Two Math", "Latin Modern Math", math`；行内公式与正文同字号，行间公式 1.1em。
- **行间公式**：独占一块，居中；有编号时编号 `(1)` 等宽 `fg-3` 靠右。公式比主栏宽时，公式块自身横向滚动（边缘渐隐），不撑破页面。
- 行内公式随文字换行；过宽的行内公式（矩阵等）不拆，允许该行横向溢出到公式自身的滚动盒。
- 公式在 PMC 里有三种来源：有 MathML 的走上面的渲染；只有图片的（PLOS 个别公式，`formula` 块 `mathml` 为 null、`image` 为文件名）经图片接口取图，按 `width` / `height` 占位、居中显示，编号照常靠右，`alt` 写「公式 (N)」；只有 TeX 的，后端去掉外壳后输出为 `code` 块，前端按代码块显示（见上表与附录 A.3）。
- 段落里不会夹带块级内容：后端会在公式、图、表、列表两侧把 `<p>` 切成多个块，前端按块顺序渲染即可。

**参考文献 `#references`**

- 标题：serif 24px「参考文献」+ 等宽计数 `40`。
- 有序列表；每条：左侧等宽编号（`fg-3`，右对齐，2.5em 宽）+ serif 15px、行高 1.55、`fg-2` 的著录文本（照原文，不改写）；下一行等宽小字外链 `DOI ↗ · PubMed ↗`（有哪个给哪个），再加「↩ 回到正文」。
- 默认显示前 5 条，下方「展开全部 40 条」；展开后不再收起（读者此时就是在看参考文献）。少于等于 8 条时直接全显示。

**许可与出处 `#license`**（文末版权页）

`bg-paper` + `border-default` + `radius-xl` 的一块，标题 serif 19px「许可与出处」，下面是一张两列的定义表：

| 行 | 内容 |

| DOI | `10.1136/bmjopen-2026-122934 ↗` |
| PMC | `PMC13583816 ↗`（`https://pmc.ncbi.nlm.nih.gov/articles/PMC13583816/`） |

### 3.5 无全文

「全文」区块照常出现（eyebrow「全文」），内容换成一块说明面板（`bg-paper`、`border-default`、`radius-xl`、24px 内边距）：serif 19px 标题 + 一句原因（DS 文案规则：一句话说清原因，破折号接上可能的情况）+ 按钮。三种原因：

| 原因 | 判定 | 标题 | 说明 | 按钮 |
|------|------|------|------|------|
| 不在开放获取子集（默认；也包括候选文献还没抓到、抓取出错） | 无全文、没有 PMCID、未撤稿 | 暂无开放全文 | Patra 只转载 PubMed Central 开放获取子集里的全文——这篇文献不在其中，可以去出版方页面阅读。 | 「去全文 · DOI ↗」主按钮（没有 DOI 时「去 PubMed ↗」） |
| PMC 收录但不能转载 | 无全文、无 PDF，但有 PMCID（没有开放许可、作者手稿禁发期内、PMC 桶里还没到，前端分不清，文案一并覆盖） | PMC 收录了这篇文献 | 这篇文献收录在 PubMed Central，但没有开放许可或尚未开放——Patra 不能转载正文，可以去 PMC 查看。 | 「去 PMC 查看 ↗」主按钮 ·「去全文 · DOI ↗」次按钮 |
| 已撤稿 | 详情接口 `retracted = true`（PubMed 文献类型含 `Retracted Publication`，或抓取时 PMC 标为撤稿；后端读端同口径下线全文） | 已撤稿 | 有 PMCID：这篇文献已撤稿，Patra 不展示正文——撤稿说明可以去 PMC 或出版方页面查看。没有 PMCID：这篇文献已撤稿，Patra 不展示正文——撤稿说明见出版方页面。 | 「去 PMC 查看 ↗」次按钮（有 PMCID 时）·「去全文 · DOI ↗」次按钮 |

- 无全文时：题录头、侧栏与现在一致；速览「原文阅读」显示 `—`；不出现目录卡、面包屑「目录」按钮。
- 不写"暂时""即将"这类承诺：候选文献晚些时候被抓到就自然变成有全文，页面不预告。
- 撤稿文献按无全文处理，前端只是多一个文案分支（题录头的「已撤稿」胶囊 + 这里的说明），判定看详情接口的 `retracted`。只看文献类型不够：PMC 先标了撤稿、PubMed 记录还没跟上时，页面会落到「PMC 收录了这篇文献」（2026-10-20 mini 验收发现）。

### 3.5.1 有 PDF 无正文

部分开放获取文章的 XML 没有 `<body>`（只有扫描或排版好的 PDF），后端判为 `NO_BODY`：详情接口 `hasFullText = false`、`hasPdf = true`。

- 题录头：「下载 PDF」主按钮（带文件大小）· 收藏；刊头行保留「开放获取」胶囊。
- 侧栏：操作卡「下载 PDF」主按钮 · 收藏 ·「在 PMC 查看原文 ↗」；速览「原文阅读」`—`；没有目录卡与面包屑「目录」按钮。
- 全文区块：说明面板，标题「只有 PDF 版本」，说明「PubMed Central 只提供了这篇文献的 PDF，没有可以在页面上阅读的正文——下载 PDF 即可阅读全文。」按钮「下载 PDF」主按钮 ·「去全文 · DOI ↗」次按钮。
- **PDF 同样要署名**：说明面板下半部分（`border-subtle` 分隔）放一张小定义表：许可（为空时「许可见原文」，下附「PDF 按原文许可转载，未作改动。」）、数据来源、PMC 链接、抓取日期（附「PDF 抓取于 …，可能不是最新版本，以 PMC 原文为准。」）。数据来自全文接口：`NO_BODY` 时它返回 200、`body` 为空，署名字段照常给（附录 A.1）。

### 3.6 全文加载中 / 加载失败

全文走独立接口（决策 C），详情先出，全文区块后到：

- **加载中**：区块头（eyebrow + 统计行占位条）+ 三组"标题条 + 4 行段落条"的纸面微光骨架；侧栏目录卡显示 5 条骨架条。
- **加载失败**（详情说有全文，但全文接口超时或 5xx）：区块内一块说明面板，标题「全文没能加载」，说明「网络或服务出了问题——刷新页面再试，或先下载 PDF。」按钮「重新加载」主按钮 ·「下载 PDF」次按钮（有 PDF 时）。不把整页打到全局错误页。

### 3.7 数据来源

接口形状以后端工程 spec 为准：详情接口新增字段见其 7.2 节，全文接口见 7.3 节，正文结构（章节 / 段落 / 图 / 表含合并单元格 / MathML 公式 / 列表 / 引文框 / 文本框 / 代码 / 文末附加 / 参考文献）见 6.2 节。本简报各元素与字段的对应：

| 页面元素 | 字段 |
|---------|------|
| 「阅读全文」、目录、全文区块分支 | 详情 `hasFullText` |
| 下载按钮 | 详情 `hasPdf`、`pdfSizeBytes`（字符串） |
| 速览「原文阅读」、目录卡头、统计行 | 详情 `estimatedReadMin`；统计行的词数用全文 `wordCount` |
| 出处条与版权页 | 全文 `license`（`null` →「许可见原文」）、`source`、`pmcid`、`pmcUrl`、`fetchedAt`、`isManuscript` |
| 版权页的作者、出处 | 详情已有的作者、刊名、卷期（PMC 引文串不在接口里，用详情字段拼） |
| 无全文的原因 | 详情已有的 `pmcid` 与文献类型 |

## 6. 交互与响应式

- **锚点跳转**：所有页内跳转（阅读全文、目录、引用、图表交叉引用、回到正文）用平滑滚动（减弱动效时瞬跳），目标统一 `scroll-margin-top: 117px`（TopNav 57 + 面包屑 44 + 16 留白），并更新地址栏 hash（`#fulltext`、`#s2`、`#ref-R12`），方便分享到某一节。
- **键盘**：目录项、引用、图片（作为按钮）、展开按钮都能 Tab 到，焦点环用全站 `ring-focus`；放大层打开时焦点移入、Tab 困在层内、关闭后焦点回到原图片；目录面板同理。
- **阅读进度**：面包屑底部进度条照旧跟随整页（含摘要部分），不单独做"正文进度"。
- **断点**：≥ 1100px 主栏 + 340px 侧栏、栏距 56px；980–1100px 栏距 40px；< 980px 单栏 + 面包屑「目录」；< 540px 出处条折两行、表下出现"左右滑动"提示。
- **打印**：本版不做打印样式（下载 PDF 即可）。

## 7. 约束

- **视觉**：沿用「叶脉 · 学术编辑风」与现有 token（`src/styles/tokens.css`），不新增颜色；正文区不出现阴影卡片，图托盘与表格盒只用发丝线。
- **技术**：全文接口在服务端取回（RSC），用 Suspense 流式出全文区块；正文渲染器只认白名单节点，不渲染后端给的 HTML 字符串（决策 C）。不引入新的前端依赖（MathML 原生渲染、目录高亮用 IntersectionObserver）。
- **图片与 PDF** 一律经门户同源 Route Handler 转发（决策 F），浏览器拿不到 MinIO 或网关地址。
- **可访问性**：全文区块是 `<article aria-labelledby>`；章节标题是真实的 `h2` / `h3`（详情页 `h1` 是文献标题）；图用 `<figure>` + `<figcaption>`，`alt` 用图题；表用 `<table>` + `<caption>`、`<th scope>`；放大层与目录面板是 `role="dialog"` + `aria-modal`。
- **暗色模式**：不做。

## 附录 A. 给后端（PAP-86 / PAP-87）

接口以后端工程 spec 为准，这里只列设计侧在 spec 之外的要求。

### A.1 详情接口与全文接口的补充（已写进后端 spec 与计划）

| 要求 | 落地形状 |
|------|---------|
| 下载按钮旁显示文件大小 | 详情接口新增 `pdfSizeBytes`，能下 PDF 时才有值；Long 按仓库规则输出成字符串（如 `"2621440"`），PAP-88 的 zod 按字符串解析 |
| 有 PDF 无正文时也要署名（决策 D） | `NO_BODY` 时全文接口返回 200：`body`、`wordCount`、`estimatedReadMin` 为 `null`，`pmcid`、`pmcUrl`、`license`、`source`、`fetchedAt`、`isManuscript` 照常返回；既读不了全文、也下不了 PDF 时才 404 |
| 图片按比例占位、加载不跳动 | `figure` 块新增 `width`、`height`（像素），取不到时为 `null`（此时退回无占位的淡入）；正文图片多为 `.webp`，图片接口返回 `image/webp` |

无全文的原因前端自己判断：有 PMCID →「PMC 收录但不能转载」；`retracted = true` →「已撤稿」。`retracted` 是 2026-10-20 补的字段，后端合并 PubMed 文献类型与抓取时 PMC 的撤稿标记。

### A.2 正文结构的呈现约定

spec 6.2 的每种块与行内节点都在 §3.4 有呈现规则；`back`（致谢、脚注、附录）放在正文之后、参考文献之前；补充材料整节不出现。

### A.3 公式编码：两处要在解析时处理（2026-10-19 实测）

1. **BMC 全系与 Sci Rep 只有 LaTeX，没有 MathML。**（spec 6.2 已定：这类公式输出为 `code` 块放 TeX 原文；页面按 §3.4 的代码块显示，带「公式 · LaTeX 源码」小标。以下是当时的实测依据。） 按期刊各抽 12 篇 2025 年开放获取文章：PLoS Comput Biol、Front Public Health、eLife、Nat Commun、Stat Med、PLoS One 的公式都带 MathML；Sci Rep 4 篇、BMC Med Res Methodol 6 篇含公式的文章全部只有 `<tex-math>`（一整段 `\documentclass{minimal}…$$…$$`），没有 `<alternatives>`、没有公式图片（样本 PMC12632047.1）。后端已定：去掉 documentclass 外壳，只把公式本身放进 `code` 块的 `text`。
2. **Wiley 等出版方的 MathML 用了 `<mml:mfenced>`**（PMC12670376.1 第一个行间公式就是）。Chrome 109 起实现的 MathML Core 不支持 `mfenced`，括号会消失。spec 6.2 定为后端只去命名空间前缀、不做规范化，白名单放在门户，所以改写落在 PAP-88：渲染时把 `mfenced` 换成 `mrow` + 两个 `mo` 括号（含 separators），画板的压力样例就是这样改写后的效果。
3. **`mtable` 的 `columnalign` 在 Chrome 里不生效**（同样不在 MathML Core 里）。分段函数（cases）原文是左对齐，不处理会全部居中、难以阅读。后端原样保留 `columnalign`，前端用 CSS（`mtable[columnalign="left"] mtd { text-align: left }`）补上；画板的压力样例已按此处理。

### A.4 其他

- **阅读时长**：`ceil(wordCount / 230)`；后端已定 `wordCount` 不计参考文献、公式、表格单元格和 `code` 块，表题、表注照常计入。（实测依据：Stat Med 那篇 PMC12670376 若把 MathML 记号算进去是 19,335 词，去掉后是 11,076 词、49 分钟。）
- **图片**：桶里的正文图片是 `.webp`（BMJ Open、JAMA Netw Open）或 `.jpg`（Wiley）；JATS 不带像素尺寸，抓取时记下宽高。Route Handler 透传 `Content-Type` 与缓存头（由 catalog 设置，决策 F）。
- **PDF 文件名**：`Content-Disposition: attachment; filename="PMC13583816.pdf"`。
- **"有全文无 PDF"是真实状态**：PMC13633532（JAMA Netw Open，开放获取）的元数据 `pdf_url` 为 null。
