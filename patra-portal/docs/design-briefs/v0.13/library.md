# 文献库与收藏 — Design Brief

> v0.13 唯一一份设计简报。设计系统与代码库已 onboard，本简报只交增量。
> **产品定义以 release spec 为准**：`docs/patra/release-specs/v0.13-library.md` 2.1 节（收藏、收藏夹、导出与引用、分享、账号状态）与第 4 节决策 D、E、F、H、I。本简报只定页面、状态与文案；两者不一致时以 spec 为准，简报里发现的缺口列在 §10，不在这里改规则。
> **接口契约以后端工程 spec 为准**：PAP-108（identity 对外契约）、PAP-109 / PAP-110（catalog 解析、卡片、引用与导出）、PAP-113（收藏与收藏夹）。写本简报时这几份都还在写，页面对它们的要求列在附录 A。
> 可交互画板：Claude Design 画布「v0.13 文献库」<https://claude.ai/artifact/BoLjKpkaQhzotxdiNJdeP6>（桌面 1440 + 移动 375，5 页 20 块，场景用 Tweaks 切换）；快照 `docs/patra/design/snapshots/2026-10-24-library-hifi.zip`。
> 同版相关：Linear PAP-107（本简报 + 画板）→ PAP-114（收藏与文献库）/ PAP-115（分享与页面信息）。

**目标**：医生和科研人员在看文献的地方一键收进自己的文献库，按收藏夹整理、写备注，导出到 Zotero / EndNote 或复制规范引用，把收藏夹公开给同事；同事能打开、复制成自己的。

## 0. 策略与定位

- **收藏是工具，不是社交。** 页面上没有任何「多少人收藏」的数字、没有点赞评论、没有热门收藏夹。能出现的数字只有「我的」：文献库的篇数、某个收藏夹的篇数。文献详情页事实条的「收藏」格**删掉**（不是改数字）。
- **一处收藏，处处可整理。** 收藏按钮在三处（详情页页头、首页文献卡片、检索结果列表项）行为完全一致：点一下就收进文献库，同时弹出浮层，就地放进收藏夹、写备注。用户不必去文献库也能整理完。
- **文献库是自己的工作台**（`/library`），**公开收藏夹页是给别人看的阅读页**（`/collections/{id}`）。管理动作（改名、公开开关、移出、批量）只在文献库里；阅读页只有「复制为我的收藏夹」「导出」「复制引用」「分享」。（2026-10-24 用户定）
- **导出与引用跟着「范围」走。** 单篇在详情页分享面板里；多篇、一个收藏夹、整个文献库在文献库里；别人的公开收藏夹在阅读页上也能导出和复制引用（2026-10-24 用户定）。四种导出格式、四种引用格式在所有入口长得一样。
- **mini 是 HTTP。** 浏览器的剪贴板接口用不了，所有「复制」都要走降级（§3.8），且降级后仍要让人一眼知道怎么完成复制。
- **互动区块独立降级。** interaction 出问题时，文献页、检索页、首页、主页照常出：收藏按钮显示「暂不可用」，文献库页与公开收藏夹页显示错误块 + 重试；主页的收藏夹标签对本人显示错误块，对别人直接不出（别人本来就不知道有没有）（决策 H，§3.17）。
- **渐进式披露**：
  - 默认层：收藏按钮的两态（收藏 / 已收藏）；文献库的列表（标题、期刊、日期、作者）；收藏夹的名称与篇数。
  - 深数据层：收藏浮层里的收藏夹勾选与备注；列表项上的所在收藏夹与备注；导出对话框里每种格式适用的软件；公开开关下的可见范围说明。
- **流程闭环**（画板要能从头点到尾，AC 2）：
  1. A 在检索结果点「收藏」→ 浮层「已收进文献库」→ 新建收藏夹「组会」→ 写备注；在详情页再收一篇，勾进「组会」和「心衰综述」两个夹。
  2. A 进文献库 →「组会」→ 打开「公开」开关 → 复制链接。
  3. B 在 A 的主页点「收藏夹」标签 → 打开「组会」→「复制为我的收藏夹」→ toast →「去看看」进自己的文献库。
  4. A（或 B）在「组会」点「导出」→ 选 RIS → 下载；点「复制引用」→ 选 GB/T 7714-2015 → 复制。

## 1. 用户与场景

| 用户 | 场景 |
|---|---|
| 检索中的医生 / 研究者 | 检索结果里扫到一篇有用的，点收藏，不离开结果页就放进「组会」夹 |
| 读文献的人 | 详情页读完，收藏 + 写一句备注「第 3 张表的亚组结果组会讲」，顺手复制一条 GB/T 7714-2015 引用贴进论文 |
| 准备组会 / 综述的人 | 在文献库里按收藏夹看，按出版日期排序，选中几篇导出 RIS 进 Zotero |
| 想分享给同事的人 | 把「组会」设为公开，复制链接发到群里；或让同事在自己主页的「收藏夹」里找到 |
| 收到链接的同事（可能没登录） | 打开公开收藏夹，直接导出 / 复制引用；登录后复制成自己的收藏夹接着整理 |
| 匿名访客 | 点收藏 → 去登录，回来接着收 |

### 2.2 跳转规则

沿用 v0.8 的 `next` 规则与 v0.12 §2.2，新增：

1. **未登录打开 `/library/**`**：跳 `/login?next=<原路径>`。
2. **未登录点收藏按钮**：跳 `/login?next=<当前页路径>`；回来后按钮是该文献的真实状态，**不自动替他收藏**（他可能在别处已经收过；自动收藏还会在他没看见时弹浮层）。
3. **未登录点「复制为我的收藏夹」**：按钮文案就是 `登录后复制`，跳 `/login?next=/collections/<id>`。回来后不自动复制。
4. **`/library/<不存在或不是自己的收藏夹>`**：404（`NotFoundState kind="collection"`，§3.14）。
5. **所有者本人打开自己的 `/collections/<id>`**：正常显示阅读页 + 顶部本人提示条（§3.14），不跳转。
6. **刚删除当前收藏夹**：跳 `/library`。
7. **复制成功后的「去看看」**：→ `/library/<新收藏夹 id>`。
8. **`/u/<旧名>/collections`**：与主页一样，307 到新名（v0.12 §2.2 第 4 条）。

### 2.3 导航入口

- **顶栏（桌面，已登录）**：头像左边一个文字按钮 `文献库`（图标 `Bookmark` 15px + 文字，`btnText` 样式，当前在 `/library/**` 时 `fg-1` + 下划线，其余 `fg-2`）。未登录不显示。（我定的：文献库是本版主功能，只放进头像菜单太深。）
- **用户菜单（桌面）**：`个人主页`、`我的文献库`（图标 `Library`）、`设置` | `退出登录`。
- **移动全屏菜单账号块**：头像行下面的两个并排按钮改为三个等宽：`主页`、`文献库`、`设置`；再下面整行 `退出登录`。
- **收藏浮层**：头部右端 `查看文献库 →`。
- **公开收藏夹页（本人视角）**：提示条里 `在文献库中管理`。
- **主页收藏夹标签（本人视角、为空）**：`去文献库`。

## 3. 每屏内容 ← 最关键

### 3.1 收藏按钮（spec 的三处 + 公开收藏夹页）

spec 的三处入口加上公开收藏夹页的条目（访客收自己的），共用一个组件 `SaveButton`，只有外形不同：

| 位置 | 外形 | 位置细节 |
|---|---|---|
| 详情页页头 | 胶囊次按钮（`btnSecondary`，48px 高），图标 15px + 文字 | 操作行：主按钮之后（§3.3） |
| 首页文献卡片 `PaperCard` | 32px 圆形图标按钮（现有 `compact` 形态） | 底栏最右端（不变） |
| 检索结果列表项 `PaperListItem`（**新增**） | 32px 圆形图标按钮 | 标题行右端：标题与按钮两列，`grid-cols-[minmax(0,1fr)_32px] gap-4`，按钮与标题首行顶对齐；窄屏同样 |
| 公开收藏夹页条目（§3.14） | 同检索结果列表项 | 同上；按钮是**访客自己**的状态，所有者本人看自己的夹时都是已收藏 |

文献库自己的条目上没有收藏按钮（都已收藏），换成 `···` 条目菜单（§3.10）。

**状态**（各位置一致，按钮本身）：

| 状态 ID | 呈现 |
|---|---|
| `save.idle` | 描边图标 `Bookmark`（`fg-3`）；胶囊形态文字 `收藏` |
| `save.saved` | 实心图标（`clay-500` 填充、`clay-600` 描边）；胶囊形态文字 `已收藏`；`aria-pressed="true"` |
| `save.pending-status` | 「我的状态」还没回来：外观同 `idle`，但 `aria-disabled`，不响应点击，不画骨架（避免一屏 20 个按钮闪烁） |
| `save.anon` | 外观同 `idle`；点击跳登录（§2.2 第 2 条） |
| `save.unavailable` | 「我的状态」超时或失败：图标 `fg-4`、`aria-disabled`；胶囊形态文字 `收藏暂不可用`；图标形态悬停 `title`「收藏暂不可用」 |
| `save.open` | 浮层打开时按钮保持按下态（`paper-200` 底） |

- 读屏名称：`收藏「<标题前 40 字>」` / `已收藏，管理收藏`。
- 点击 `idle`：**立即收藏**（乐观更新为 `saved`）并打开浮层；点击 `saved`：只打开浮层（**不取消收藏**，取消在浮层里，§3.2）。
- 「我的状态」是一屏一次批量请求（决策 H）；单个按钮不各自请求。

### 3.2 收藏浮层 `SavePopover`

桌面：锚在按钮下方的浮层，宽 320px，`shadow-lg`、`radius-lg`、`paper-50` 底；移动（< 880px）：底部抽屉，高度随内容、最高 80vh。

自上而下：

1. **头部**：左 `CircleCheck`（`moss-500`）+ `已收进文献库`；右 `查看文献库 →`（文字链接，`fg-2`）。
   - 收藏请求进行中：左侧换成 14px 转圈 + `正在收藏…`。
   - 已经收藏过、这次只是打开：头部写 `已在文献库中`，加入时间 `10 月 24 日收藏` 在下面一行 `fg-3` 小字。
2. **放进收藏夹**（小标题 `收藏夹`，等宽 `2xs` 大写 `fg-3`）：
   - 勾选列表，每行：复选框（`CHECK_INPUT`）+ 名称（截断）+ 右端可见性图标（`Lock` 私有 / `Globe` 公开，`fg-3` 14px）。**勾上 / 取消立即生效**，行内出现 12px 转圈直到返回。
   - 排序：最近更新的在前（与文献库侧栏一致）。
   - 列表最多显示 6 行高（约 216px），超出滚动；收藏夹 ≥ 9 个时列表上方出现筛选框 `筛选收藏夹`（只在本地过滤）。
   - 某个夹已满 5,000 篇且这篇不在里面：该行复选框禁用，名称后 `已满` 小字（`fg-3`）。
   - 一个收藏夹都没有：列表位置一行 `fg-3`：`还没有收藏夹，新建一个来整理文献。`
3. **新建收藏夹**：列表下方 `+ 新建收藏夹`（文字按钮）→ 原地变成输入框（占位 `收藏夹名称`，自动聚焦）+ `创建`（小主按钮）。回车或点创建 → 新夹出现在列表**第一行并已勾上**。`Esc` 收起输入框。已有 200 个时这个按钮禁用，旁边 `最多 200 个收藏夹`。新建的收藏夹一律私有（不在浮层里给公开开关）。
4. **备注**（小标题 `备注`）：
   - 没有备注：`+ 添加备注`（文字按钮）。
   - 有备注：备注正文（`fg-2`，最多 3 行截断）+ `编辑`。
   - 编辑态：多行输入框（4 行高，自动增高到 8 行），右下角计数 `86 / 500`（按字素），按钮 `保存`（小主）/ `取消`（文字）。保存中 `保存中…`；成功回到展示态，不出 toast。清空后保存 = 删除备注。
5. **分隔线 + `从文献库移除`**（文字危险按钮，`rust-500`）：
   - 没有备注、也不在任何收藏夹里：立即移除，浮层关闭，按钮回 `idle`，toast `已从文献库移除` + `撤销`（5 秒内点撤销 = 重新收藏，无损）。
   - 有备注或在收藏夹里：浮层底部原地展开确认块（`rust-50` 底）：`移除后，这篇的备注会删除，也会移出 2 个收藏夹。` + `移除`（小危险主按钮）/ `取消`。确认后同上，但 toast **不带撤销**（备注与归属已删，撤销不回来）。
- **关闭**：点外部、`Esc`、移动下滑；焦点回到收藏按钮。浮层里任何进行中的请求关闭后照常完成。
- **键盘**：打开时焦点在第一个复选框（没有收藏夹时在 `新建收藏夹`）；`Tab` 顺序同视觉顺序。

**浮层错误**（不出 toast，在出错的位置就地显示，§4.1）。

### 3.3 文献详情页页头（改）

在 PAP-89 的页头上改（`PaperHeader`），结构不变：

1. **作者 · 刊名 · 日期**：年份换成**按精度的出版日期**（§3.19）。
2. **事实条**：删掉「收藏」格，其余不变。
3. **操作行**（桌面，> 540px）：`阅读全文 ↓`（主）· `下载 PDF` · `收藏` · `分享` · `在 PMC 查看原文 ↗`。`分享` 是胶囊次按钮，图标 `Share2`。仍是「全页唯一一组操作」。
4. **操作行**（≤ 540px）：**方案 A**（推荐）——
   - 第一行：主按钮占满整行（`阅读全文 ↓` 或无全文时的外链主按钮）。
   - 第二行：次按钮三等分 `下载 PDF` · `收藏` · `分享`（48px 高，图标在上、文字在下的竖排紧凑形态，`text-xs`）；没有 PDF 时两等分 `收藏` · `分享`；无全文时 `下载 PDF` 不出现。
   - 第三行：`在 PMC 查看原文 ↗`（左对齐文字链）。
   - **方案 B**（对比用）：主按钮 + `收藏`（图标按钮）+ `···`（菜单：分享、下载 PDF、在 PMC 查看原文）。画板上用静态板 `HeaderNarrow` 并排对比两案；**定 A**，理由是收藏和分享是本版要培养的动作，不该藏进菜单。
5. 收藏按钮不可用时（§3.17），`收藏` 位置显示禁用的 `收藏暂不可用`，宽度不变，不挤动其他按钮。

### 3.4 分享面板 `SharePanel`（详情页）

桌面：锚在 `分享` 按钮下的浮层，宽 400px；移动：底部抽屉。

1. **链接**：小标题 `链接`；一行只读输入框（等宽 `text-xs`，内容是规范地址，如 `http://patra.mini/papers/12345`，过长时中间省略）+ `复制链接`（次按钮）。
2. **引用**：小标题 `引用`；格式分段控件四项 `GB/T 7714-2015` · `Vancouver` · `APA` · `AMA`（默认上次用的，第一次是 GB/T 7714-2015；记在浏览器本地，换设备不同步）；下面引用预览框（`paper-100` 底、`radius-md`、衬线 `text-sm`、可选中、最多 6 行可滚动）；`复制引用`（次按钮）。
   - 预览加载中：两行骨架；失败：预览框里 `引用暂时生成不了` + `重试`（文字按钮），`复制引用` 禁用。

### 3.5 复制引用对话框 `CiteDialog`

### 3.7 页面上的「数字」规则

### 3.8 复制与剪贴板降级（全站共用 `useCopy`）

依次尝试，前一步失败才走下一步：

1. `navigator.clipboard.writeText`（只在 HTTPS / localhost 可用）。
2. 选中要复制的文字（链接输入框全选 / 引用预览框全选）后 `document.execCommand("copy")`。
3. 都失败：**保持文字选中**，按钮位置换成提示 `已选中，按 ⌘C 复制`（Windows / Linux 显示 `Ctrl+C`；触屏设备显示 `已选中，长按文字复制`），提示保留到选区变化。

- 第 1、2 步成功都显示按钮内 `已复制`。
- 第 3 步提示用 `aria-live="polite"` 播报。
- mini 上实际会落在第 2 步（HTTP 下 `execCommand` 仍可用）；画板用 Tweak `剪贴板` 切三种结果。

## 6. 交互与响应式

- **断点**：文献库、公开收藏夹页、主页沿用 880px；详情页页头沿用 PAP-89 的 540px（§3.3）。
- **乐观与否**（不调用 `router.refresh()`，决策 H）：
  - **乐观**（先改界面，同时显示一个小的进行中标记，返回后标记消失；失败回滚并就地报错）：收藏按钮（实心 + 浮层头部 `正在收藏…`）、浮层里的勾选（行内 12px 转圈）、移出收藏夹、关掉公开。
  - **不乐观**（等返回再改界面，期间显示进行中文案并禁用）：备注保存（`保存中…`）、新建 / 编辑 / 删除收藏夹、打开公开（`设置中…`，因为可能被资格拒绝）、批量操作、复制收藏夹、导出。
- **焦点**：浮层 / 对话框打开时焦点在第一个可操作项，关闭回到触发按钮；行内新建收藏夹自动聚焦输入框；删除条目后焦点落到下一条的标题链接。
- **键盘**：浮层 `Esc` 关闭；条目菜单 `Shift+F10` 也能打开；批量模式下空格勾选当前条目。
- **读屏**：收藏状态变化 `aria-live="polite"` 播报 `已收藏` / `已从文献库移除`；批量栏出现时播报 `已选 12 篇`；复制结果播报 `已复制` 或降级提示。
- **动效**：浮层、对话框、批量栏入场沿用现有时长与缓动；收藏按钮从描边到实心用 `dur-fast` 填充 + 1.1 倍回弹（现有 compact 已有）；移除的条目淡出 `dur-normal`；尊重「减少动态效果」。
- **移动**：浮层 / 面板 / 对话框都是底部抽屉；输入框 17px、按钮 48px 高；吸底批量栏避开安全区；视图切换走抽屉。
- **元素状态**：hover / active / focus / disabled 都要给出，新增的有：收藏按钮三种外形、浮层复选行、侧栏项、条目菜单按钮、格式分段控件、导出格式卡、公开开关、批量栏按钮、主页标签、收藏夹卡片。

## 7. 约束

- **视觉**：沿用「叶脉 · 学术编辑风」与设计系统 token（`patra-portal/src/styles/tokens.css` + `@theme`）。**不新增颜色与字族**：危险 `rust`、警示 `amber`、成功 `moss`、信息 `slate`、强调 `clay`；私有 / 公开用图标（`Lock` / `Globe`）区分，不用颜色区分。
- **技术**：Next 16 App Router / Tailwind v4 / base-ui(shadcn)。互动区块独立 Suspense + 超时（决策 H）；门户只经 interaction 拿收藏数据、经 catalog 拿文献与引用。
- **可访问性**：沿用 v0.12 §7；另：收藏按钮用 `aria-pressed`；可见性图标配读屏文字（`私有` / `公开`）；吸底批量栏 `role="toolbar"`。
- **暗色模式**：不做。
- **本版边界**（设计稿里**不要**出现）：任何收藏数 / 热度 / 「N 人收藏」、点赞、评论、讨论、关注、通知、标签（tag）、嵌套文件夹、协作收藏夹、审核与举报、二维码海报、系统分享、短链、分享图、收藏期刊 / 作者 / 机构 / MeSH、收藏夹封面图、主页标签上的个数。

## 10. spec 缺口、冲突与待拍板

**2026-10-24 用户已定**：

1. 自己的收藏夹在 `/library/{id}` 管理，`/collections/{id}` 只做阅读页（本人打开有提示条）。
2. 主页用标签栏「关于 · 收藏夹」，收藏夹标签对应 `/u/{用户名}/collections`。
3. 出版日期写法见 §3.19。
4. 访客可以导出、复制引用别人的公开收藏夹（附录 A PAP-113 第 9 条）。

**与 spec / Issue 的冲突或缺口**：

1. **简报随哪个 PR**：release spec §2 写「设计简报在后端 PR 合并前完成的，随后端 PR 合入」；PAP-107 AC 写「随交付时仍在开发的第一个代码 PR」；派发本 Issue 的规划会话写「随前端 PR 提交，不随后端 PR」。本简报按规划会话执行（随前端 PR），release spec §2 那句要同步。
2. **检索结果列表项没有收藏按钮**：spec 2.1.1 把它列为入口之一，但 v0.7 起 `PaperListItem` 有意不放（注释「本版边界 D」）。本版按 spec 新增（§3.1），列表项注释要一起改。
3. **「已注销用户」占位的实际出现位置**：spec 2.1.5 要求收藏夹所有者位置显示占位；但已注销用户的 `profileVisible` 恒为假，公开收藏夹页对任何人都是 404，复制品也不记来源。占位外观仍按 §3.14 画（接口给占位时兜底），实际几乎不可见。
4. **公开收藏夹页不显示所有者的备注**：spec 只说「复制时备注不复制」，没说阅读页显不显示。按「备注是私人的」处理，阅读页不显示（我定的）。
5. **详情页断点**：Issue 写「窄屏」，详情页实际断点是 540 / 980 而不是全站的 880；页头方案按 540 画。

**简报里由我定的设计点**（看到不对就推翻）：

1. 点收藏 = 立即收进文献库 + 弹浮层；已收藏再点只打开浮层，取消在浮层里（有备注或在夹里时确认，否则给撤销）。
2. 浮层里勾选收藏夹立即生效、行内新建并自动勾上；新建的收藏夹一律私有。
3. 详情页加「分享」按钮，单篇的复制链接 / 复制引用 / 导出都在分享面板里；窄屏操作行用方案 A。
4. 顶栏加「文献库」入口（桌面），用户菜单与移动账号块也加。
5. 文献库侧栏照设置页分区导航的样式；移动用视图切换抽屉；每页 50 篇；选择只在当前页。
6. 文献库条目不显示摘要和证据徽章，显示归属胶囊与备注。
7. 已失效条目显示快照标题 + 「已失效」，不可点，只能改备注、移出、移除；批量导出 / 引用自动跳过并说明。
8. 公开开关放在收藏夹头部（不放进编辑对话框）；未验证时提前禁用；按主页可见性给出三种可见范围说明。
9. 公开收藏夹页的复制不确认、可重复；toast 写实际名称与新收进篇数，带「去看看」。
10. 主页标签不带个数；别人视角没有可见的公开收藏夹时不渲染标签栏。
11. 引用 / 导出格式记住上次的选择（浏览器本地）。
12. 剪贴板三步降级（API → execCommand → 保持选中并提示快捷键）。
13. 「加入时间」在收藏夹里指加入该夹的时间，在全部 / 未分类里指收藏时间。
14. 导出范围加「未分类」；导出与复制引用在每个视图头部都有。
15. 复制别人的收藏夹整体成败，已失效条目不复制并在 toast 里说明。
16. 文献页、期刊页的页面信息模板（§3.18）；canonical 与复制链接用配置的门户公开地址。
17. 乐观更新只用于收藏、勾选、移出、关公开；其余等返回（§6）。
18. 复制别人的收藏夹时，简介跟着复制（spec 只说同名、备注不复制）。
19. 所有者看自己的公开收藏夹页时，条目上的收藏按钮都是「已收藏」。
20. 手机视图切换抽屉里，可见性用文字「私有 / 公开」标在收藏夹名前。
