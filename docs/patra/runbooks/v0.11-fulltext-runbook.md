# v0.11 全文阅读 运维手册

> 版本：[v0.11 Full Text Reader](../release-specs/v0.11-fulltext-reader.md) · 工程 spec：[全文阅读后端](../specs/2026-10-19-fulltext-reader-backend-design.md)

本手册记录 v0.11 新增的三个 XXL-Job 怎么建、怎么跑、出问题怎么查。XXL-Job 的任务都在控制台手工建，没有种子 SQL。

## 1. PubMed 增量同步（`pubmedUpdateSyncJob`）

从进度表 `cat_pubmed_update_file` 最后一个成功文件的下一个开始，按文件号依次处理 NLM updatefiles 到最新；遇到失败的文件就停下，下次运行从它重试。

### 1.1 建任务

| 项 | 值 |
|---|---|
| 执行器 | patra-catalog |
| JobHandler | `pubmedUpdateSyncJob` |
| 调度类型 | CRON `0 0 5 * * ?`（Asia/Shanghai；NLM 美东 14:00 前后发布，即北京时间次日 02:00 ~ 03:00） |
| 子任务 ID | 全文抓取任务的 ID（第 2 节建好后回填） |
| 运行模式 | BEAN |
| 阻塞处理策略 | 单机串行 |
| 任务参数 | 留空（见 1.2） |

### 1.2 参数

都可以省略，用逗号分隔：

| 参数 | 含义 |
|---|---|
| `fromFile=N` | 从文件号 N 开始。N 已经成功过时会换新的作业实例重放（用于换 `scope` 重跑） |
| `maxFiles=M` | 本次最多处理 M 个文件，首次追赶时分批用 |
| `scope=EXISTING_ONLY\|ALL` | 覆盖配置 `patra.catalog.pubmed.update-scope`。`EXISTING_ONLY` 只更新库里已有的文献 |

配置（record 默认值，环境差异在 Nacos `patra-catalog.yaml`）：

| 键 | 默认 | 开发环境（mini） |
|---|---|---|
| `patra.catalog.pubmed.update-url` | `https://ftp.ncbi.nlm.nih.gov/pubmed/updatefiles/` | 同默认 |
| `patra.catalog.pubmed.file-prefix` | `pubmed26n` | 同默认 |
| `patra.catalog.pubmed.update-scope` | `ALL` | `EXISTING_ONLY` |
| `patra.catalog.pubmed.update-start-seq` | `1335`（2026 年第一个 updatefile） | 同默认 |

### 1.3 查进度

```sql
SELECT file_seq, status, scope, updated_count, created_count, deleted_count,
       skipped_absent_count, skipped_invalid_count, doi_conflict_count, skip_error_count,
       started_at, finished_at, last_error
FROM cat_pubmed_update_file
ORDER BY file_seq DESC
LIMIT 20;
```

- `FAILED`：看 `last_error`，修好后直接再触发一次，会从这个文件续传。
- `skip_error_count` 不为 0：写入时撞了唯一约束被跳过，按 PMID 在任务日志里搜 `增量同步写入出错被跳过`。
- 另一个实例正在运行时，本次任务记成功，消息是"另一个增量同步实例正在运行，本次跳过"。
