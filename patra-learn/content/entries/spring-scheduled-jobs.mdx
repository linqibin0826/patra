<Callout kind="lead">

定时任务有两种放法。**进程内定时**：时间表写在代码里，由服务进程自己的定时器到点调方法。**调度中心**：时间表放在单独的调度服务里，到点由它回调某个服务实例去执行。Patra 的调度中心是 XXL-Job。

</Callout>

## 进程内定时：`@Scheduled`

Patra 自己写的定时任务里，只有一处用了进程内定时：通知服务给推送连接发心跳，每 25 秒一轮。

<CodeRef at="patra-api/patra-notification/patra-notification-adapter/src/main/java/dev/patra/notification/adapter/realtime/scheduler/UnreadCountStreamHeartbeatScheduleJob.java@5b1d855a5da18806b91a52f24253e64d40d743a8" lines="8-23" />

```java
/// 推送连接的心跳（PAP-145）：每 `patra.notification.realtime.heartbeat-interval`（25 秒）一轮。
///
/// 用进程内定时器、不用 XXL-Job：连接只在这个进程的内存里，心跳必须由持有连接的进程自己发；XXL-Job 是集群调度，
/// 粒度和语义都不合适。
@Component
@RequiredArgsConstructor
public class UnreadCountStreamHeartbeatScheduleJob {

  private final UnreadCountStreamRegistry registry;

  /// 给所有推送连接发一次心跳，顺带给在线的人记在站。
  @Scheduled(fixedRateString = "${patra.notification.realtime.heartbeat-interval}")
  public void heartbeat() {
    registry.heartbeat();
  }
}
```

`@Scheduled` 本身只是一个标签。要有人读它才会生效：通知服务的 `RealtimeConfiguration` 上加了 `@EnableScheduling`，Spring 才会给标了 `@Scheduled` 的方法建定时器。

注释里写的理由就是选择的标准：推送连接只存在于**这个进程的内存里**。有几个实例，每个实例都要给自己手上的连接发心跳，正好就是「每个进程各跑各的」。

## 调度中心：XXL-Job

剩下的定时任务（清理过期令牌、清理登录记录、导入 PubMed、事件补投……）都交给 XXL-Job。它分两半：

- **调度中心**（xxl-job-admin）：一个单独的服务，在控制台上为每个任务配时间（CRON 表达式）、参数和策略，记录每次执行的结果。任务都在控制台手工建，代码里没有时间表。
- **执行器**：嵌在每个 Patra 服务里，启动时把自己登记到调度中心，然后等回调。

## 防撞车：三层

「同一件事同时跑两份」有三种来源，Patra 各有一层挡。

**第一层，多个实例**：调度中心的**路由策略**决定挑哪个执行器。事件补投任务配的是「第一个」，只回调一个实例。

**第二层，同一个任务上一次还没跑完**：调度中心的**阻塞处理策略**决定怎么办。事件补投每分钟一次，配的是「丢弃后续调度」：上一轮还在跑，这一轮直接不跑。

<CodeRef at="patra-tool/patra-tool-events/src/main/java/dev/patra/tool/events/resubmit/EventPublicationResubmitJob.java@5b1d855a5da18806b91a52f24253e64d40d743a8" lines="8-11" />

**第三层，两条不同的任务做同一件事**：调度中心管不了，因为它们在它眼里是两个任务。这一层要在代码里挡。

全文抓取 `pmcFullTextFetchJob` 就是这样：同一个 handler 建了两条任务，一条是每天 PubMed 增量同步跑完后触发的子任务，一条是每小时一次的兜底。首次抓取可能跑好几个小时，兜底那条一定会撞上。

## 任务入口要薄，才好测

所有 `@XxlJob` 方法都长一个样：读参数、交给命令总线、回报结果。逻辑都在应用层，入口的测试只要验三件事：参数解析对不对、成功和失败时分别回报了什么。

`XxlJobHelper` 是静态方法，测试用 Mockito 的 `mockStatic` 把它换掉：

```java
  @Test
  @DisplayName("没给参数时处理全部到期候选，成功时 handleSuccess")
  void should_run_all_candidates_without_params() {
    try (MockedStatic<XxlJobHelper> xxl = mockStatic(XxlJobHelper.class)) {
      xxl.when(XxlJobHelper::getJobParam).thenReturn(" ");
      ArgumentCaptor<PmcFullTextFetchCommand> captor =
          ArgumentCaptor.forClass(PmcFullTextFetchCommand.class);
      when(commandBus.handle(captor.capture())).thenReturn(FullTextFetchRunStats.of(3, 2, 1, 0));

      job.execute();

      assertThat(captor.getValue().publicationIds()).isEmpty();
      xxl.verify(() -> XxlJobHelper.handleSuccess(contains("处理 3 篇")));
    }
  }
```
