## HTTPS 要解决两件事

1. **防偷看**：请求和响应加密，中间的人看到的只是乱码。
2. **防冒充**：你连上的真的是 patra.linqibin.dev，而不是一个仿冒的网站。

只有加密不够。如果你加密地把密码发给了冒充者，等于白加密。所以 HTTPS 还要有办法让服务器**证明自己是谁**，这就是证书。

## 证书是网站的身份证

证书是一份由第三方机构签发的文件，里面写着：这张证书属于哪些域名、网站的公钥是什么、有效期到什么时候。签发它的机构在上面签了名。

浏览器出厂时内置了一份**可信机构的名单**。看到证书，它做三件事：域名对不对？没过期吗？签名是不是出自名单里的机构（直接或经过中间机构）？三件都通过，才继续。

## 一张证书覆盖哪些域名

证书只对写在它上面的域名有效。`*.linqibin.dev` 这种带星号的写法叫**通配符证书**，但星号只代表**一层**：

- 能覆盖 `learn.linqibin.dev`、`patra.linqibin.dev`。
- 不能覆盖 `learn.patra.linqibin.dev`，因为它在 `linqibin.dev` 下面有两层。

## 在 Patra 里

Patra 的公网入口经 Cloudflare：浏览器和 Cloudflare 之间是 https，开着「始终使用 HTTPS」，用 http 打开会被 301 跳到 https。Cloudflare 再经隧道把请求送进 mini，隧道出口到门户那一小段是本机上的普通 http。
