## 坑

jsonb 列上的 `NOT NULL` 只拦 SQL 的 NULL。JSON 文本 `null` 转成 jsonb 是一个合法的值，不算 SQL NULL，照样写得进去。

而 Java 里的 `null` 交给 Jackson 的 `writeValueAsString`，得到的恰好就是字符串 `"null"`，不是 Java 的 `null`。

## 为什么

两种「空」不在一个层面上：

| | 是什么 | `IS NULL` | `NOT NULL` 约束 |
|---|---|---|---|
| SQL 的 `NULL` | 这一格没有值 | true | 拦住 |
| jsonb 的 `null` | 有值，值是 JSON null | false | 放行 |

v0.14 讨论那一版，interaction 的对象登记表要登记本地对象（帖子）。登记行有一列 `snapshot jsonb NOT NULL`，存标题、期刊等展示信息。写库时用的是 `jsonMapper.writeValueAsString(snapshot)` 再 `CAST(:snapshot AS jsonb)`。
