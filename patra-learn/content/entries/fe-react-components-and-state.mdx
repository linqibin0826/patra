## 组件是一个返回界面的函数

React 把页面拆成一块块组件。一个组件就是一个函数：输入一些数据，返回一段界面描述。返回的那段看起来像 HTML 的写法叫 JSX，它最后会变成真正的 DOM 节点。

门户顶部的导航栏是一个组件 `TopNav`，排序按钮组是一个组件 `SortToggle`，折叠区是一个组件 `DisclosureSection`。大组件里摆小组件，拼成整页。

<Callout kind="analogy">

组件像一张表格模板：模板本身不变，填进去的数据不同，印出来的表就不同。React 负责「数据变了就重新印一张」，你只管写模板。

</Callout>

## 状态：组件自己要记住的东西

折叠区要记住「现在是展开还是收起」。这种组件自己记、会变的数据叫状态，用 `useState` 声明：

<CodeRef at="patra-portal/src/components/portal/DisclosureSection.tsx@5df24d90973c86cd2fb1ac513bbfc4bd88fab80c" lines="27-35" />

```tsx
  const [open, setOpen] = useState(defaultOpen);
  const bodyId = useId();
  return (
    <section className="border-t border-border-default last:border-b">
      <button
        type="button"
        aria-expanded={open}
        aria-controls={bodyId}
        onClick={() => setOpen((o) => !o)}
```

`useState` 给回两样东西：当前值 `open`，和改它的函数 `setOpen`。点按钮时调用 `setOpen`，React 记下新值，再把整个组件函数重新跑一遍。这一遍里 `open` 是新值，下面的内容区就跟着显示或隐藏：

<CodeRef at="patra-portal/src/components/portal/DisclosureSection.tsx@5df24d90973c86cd2fb1ac513bbfc4bd88fab80c" lines="70-76" />

```tsx
      <div
        id={bodyId}
        hidden={!open}
        className={cn("disclosure-body pb-7", rail && "pl-[160px] @max-[580px]/main:pl-0")}
      >
        {children}
      </div>
```

代码里没有一行写「找到那个 div，把它藏起来」。你只描述「`open` 是 false 时内容区 `hidden`」，剩下的交给 React。这就是「界面是状态的函数」：同样的状态，永远画出同样的界面。

## props：父组件往下传的数据

组件的参数叫 props，由用它的父组件传进来。排序按钮组 `SortToggle` 自己不记任何状态，当前选中哪项、有哪些选项、点了之后怎么办，全由父组件告诉它：

<CodeRef at="patra-portal/src/components/portal/SortToggle.tsx@598dc3eeb2f5209dcc858393eff510a2a3c8a332" lines="6-16" />

```tsx
export function SortToggle<T extends string>({
  value,
  options,
  onChange,
  legend = "排序",
}: {
  value: T;
  options: readonly { value: T; label: string }[];
  onChange: (value: T) => void;

```

props 对子组件是只读的。`SortToggle` 想换选中项，不能自己改 `value`，只能调用 `onChange` 告诉父组件「用户选了这一项」，由父组件改自己的状态、再把新的 `value` 传下来。

## 状态放在谁那里

为什么不让对话框自己记开没开？因为能打开它的地方不止一处：桌面的「快速检索」按钮、手机菜单里的检索按钮、⌘K 快捷键，全都在 TopNav 里。它们都要改同一个状态，状态就得放在它们共同的上级，也就是 TopNav：

<CodeRef at="patra-portal/src/components/portal/TopNav.tsx@d0ca49caf72d9d9aacd7459c1054cf9131b3759e" lines="92-96" />

```tsx
  const openSearch = () => {
    setMenuOpen(false);
    setSearchLoaded(true);
    setSearchOpen(true);
  };
```

规则可以记成一句：**一份状态放在所有需要它的组件的最近共同父组件里**，再用 props 分下去。只有一个组件用的（比如折叠区的开合），就放在它自己身上。
