<Callout kind="lead">

**集合**是装一堆东西的容器，常用三种：`List`（有顺序、可以重复）、`Set`（不重复）、`Map`（按键找值）。同一种集合还分**能改**和**不能改**；Patra 规定能不改就不改。**Stream** 是对集合做「过滤、转换、收集」的一种写法，读起来像一条流水线。

</Callout>

## 三种容器

<Callout kind="analogy">

`List` 像排队名单：有先后，同一个人可以排两次。`Set` 像签到表：同一个人签多少次都只算一个。`Map` 像通讯录：按名字（键）查电话（值），名字不重复。

</Callout>

## 能改的、不能改的

同样是 `List`，背后的实现类不一样，能不能改也就不一样：

| 写法 | 能不能 add / remove | 用在 |
|---|---|---|
| `new ArrayList<>()` | 能 | 方法内部一边算一边往里装 |
| `List.of(a, b)` | 不能 | 写死几个元素，或返回空列表 `List.of()` |
| `List.copyOf(list)` | 不能 | 把别人给的列表复制一份自己留着 |
| `Collections.unmodifiableList(list)` | 不能（但会跟着原列表变） | 把自己内部的列表借给别人看 |

不能改的集合可以放心交给别人：谁拿到都改不了它，也就不会出现「我这里的列表被别处偷偷改了」。Patra 把用法写进了代码规范：

<CodeRef at=".claude/rules/code-style.md@79a711f5ee5e7ea63b9b48d6e7bc29d664684f99" lines="50-67" />

```java
// ✅ 空集合
return List.of();

// ✅ 防御性拷贝（创建独立副本）
this.items = List.copyOf(items);

// ✅ 只读视图（反映内部集合的实时状态）
public Set<String> getRegisteredIds() {
  return Collections.unmodifiableSet(this.registeredIds);
}
```

## 副本和视图，差在哪

表里最后两行最容易混：`List.copyOf` 是**副本**，复制那一刻的内容，之后跟原列表再无关系；`Collections.unmodifiableList` 是**视图**，像一扇只能看不能伸手的窗户，原列表变了，透过窗户看到的也变。

## Stream：把循环写成流水线

要从一个列表里挑出符合条件的、转成别的东西，传统写法是 `for` 循环加 `if`。Stream 把它拆成几道工序，一道接一道。机构的「官网地址」是这样取的：

<CodeRef at="patra-api/patra-catalog/patra-catalog-domain/src/main/java/dev/patra/catalog/domain/organization/model/aggregate/OrganizationAggregate.java@5073ab1358404ecd989e722373cd9f7edafe238b" lines="277-285" />

```java
  /// 获取官网 URL。
  ///
  /// @return 官网 URL，如果不存在则返回 empty
  public Optional<String> getWebsiteUrl() {
    return links.stream()
        .filter(OrganizationLink::isWebsite)
        .map(OrganizationLink::value)
        .findFirst();
  }
```

- `links.stream()`：把链接列表变成一条流；
- `filter(…)`：只留下是官网的链接（`OrganizationLink::isWebsite` 是「拿每个链接调它的 `isWebsite()`」的简写）；
- `map(…)`：把链接换成它的地址字符串；
- `findFirst()`：要第一个。可能一个都没有，所以结果是 `Optional<String>`，一个「可能为空的盒子」。

## 收集成新的集合

流水线的最后一步也可以是「装进一个新集合」。取用户名片的那段，就把 identity 返回的列表收集成了一个不能改的 Map：

<CodeRef at="patra-api/patra-interaction/patra-interaction-infra/src/main/java/dev/patra/interaction/infra/subject/user/UserDirectoryAdapter.java@5073ab1358404ecd989e722373cd9f7edafe238b" lines="57-59" />

```java
    return summaries.stream()
        .collect(
            Collectors.toUnmodifiableMap(UserSummaryResp::userId, UserDirectoryAdapter::toCard));
```

意思是：每个摘要拿 `userId` 当键，用 `toCard` 换成名片当值，装进一个不能改的 Map。前面 `getParents()` 结尾的 `.toList()` 也是同一类收尾，收集成一个不能改的 List。
