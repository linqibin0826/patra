## 服务器不是一台神秘的机器

「服务器」这个词有两层意思，新手最容易混：

- 一台一直开机、放在机房或家里角落的**机器**；
- 一个一直在等请求的**程序**。

我们说的「服务器」，多数时候指第二个：一个启动之后不退出、守着某个编号、有人敲门就回答的程序。一台机器上可以同时跑很多个。

<Callout kind="analogy">

一栋写字楼就是一台机器。楼的地址（IP）告诉你去哪栋楼；楼里每家公司有自己的房间号（端口）。你拿着地址到了楼下，还得说「我找 9528 室」，才能见到网关，而不是 4000 室的门户。

</Callout>

## 端口：一台机器上的门牌号

端口是一个 0 到 65535 的数字。程序启动时向系统申请一个端口，之后发到这个端口的请求就交给它。三条规则：

1. **一个端口同一时间只属于一个程序**。第二个程序想占同一个，会报「地址已被占用」之类的错误并启动失败。
2. **请求必须带上端口**才能找到对的程序。网址里不写端口时用默认值：`http` 是 80，`https` 是 443。
3. 端口号本身没有含义，用什么数字是约定。

## localhost：只对自己说话

`localhost` 是一个特殊的名字，永远指「我自己这台机器」，对应的地址是 `127.0.0.1`。开发时门户和网关都跑在你自己的电脑上，浏览器访问 `localhost:4000` 就是在找本机的 4000 端口。

<Callout kind="warn">

`localhost` 在别人的电脑上指的是别人自己。你不能把 `localhost:4000` 发给同事让他打开你的页面。

</Callout>
