## 坑

v0.12 用户中心那一版做资料页的「机构」和「关注领域」选择器，用的是 base-ui 的 Combobox。设计要的是：用户从候选里点一项，输入框清空，选中的东西变成下方的一张卡片（胶囊）。

实际效果是：点选之后，输入框里留着刚选的条目名。原因是 base-ui 选中候选后，会以 `reason: "item-press"` 调一次 `onInputValueChange`，把条目名回填进输入框，覆盖了我们的清空。

<Callout kind="warn">

jsdom 里复现不了这个回填，组件单测是绿的。要在真浏览器里点一次才看得到。

</Callout>

## 怎么避开

`onInputValueChange` 的第二个参数带着这次修改的原因。是 `item-press` 就不接受：

<CodeRef at="patra-portal/src/components/settings/profile/MeshInterestPicker.tsx@fe4c6bb68c591a9c9b5fe80f76bbfbbbc6aeae75" lines="166-176" />

```tsx
<Combobox<MeshSuggestion>
  items={suggestions}
  filter={null}
  value={null}
  inputValue={input}
  onInputValueChange={(next, { reason }) => {
    // 选中候选时 base-ui 会把条目名回填进输入框；这里选中后要清空（或换成卡片），不接受回填
    if (reason !== "item-press") setInput(next);
  }}
  onValueChange={(suggestion) => pick(suggestion)}
>
```

机构选择器还多忽略了一种原因 `input-clear`：候选收起后，base-ui 会把输入同步成已选值（没有已选值就是清空）。设计要求按一次 Esc 只收起候选、保留用户打的字，所以这次同步也不接受。
