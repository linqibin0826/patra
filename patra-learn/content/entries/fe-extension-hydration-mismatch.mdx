## 坑

v0.8 账号登录那一版本地验收时，作者在自己的 Chrome 里打开门户，Next 的开发浮层报：「A tree hydrated but some attributes of the server rendered HTML didn't match the client properties」。标红的一行是 `<html>` 上的 `data-immersive-translate-page-theme="light"`。

这个属性来自一个翻译类的浏览器扩展：它在 React 接管页面之前就往 `<html>` 上写了属性。React 水合时发现浏览器里的 DOM 和服务端给的 HTML 不一样，于是报错。

## 怎么分辨

用 curl 拿服务器返回的原始 HTML，看 `<html>` 标签上到底有哪些属性：

```bash
curl -s http://localhost:<门户端口>/ | grep -o '<html[^>]*>'
```

当时的结果是 `<html>` 上只有 `lang`、`data-scroll-behavior`、`class` 三个属性，源码里也没有那个名字。服务器没给，浏览器里却有，就是扩展加的。

另一个办法是开一个无痕窗口（默认不加载扩展）再打开页面，不报了就是扩展的事。

## 影响与处理

- 只在开发模式报。生产构建不比对这类属性，用户看不到，功能也不受影响。
- 可选的修法是给 `<html>` 加 `suppressHydrationWarning`。它只管这一层元素的属性差异，不会把子元素的真问题一起盖住。
- 作者觉得无所谓，没有加。再遇到时知道原因、直接说明即可。
