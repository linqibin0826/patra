## 一页网页是三层叠起来的

Patra 是一个医学文献网站。读者在浏览器里打开的那部分叫**门户**（代码在仓库的 `patra-portal/` 目录）。打开门户任何一页，看到的东西都由三种文件叠成：

| 层 | 管什么 | 门户顶栏「快速检索」按钮上的例子 |
|---|---|---|
| HTML | 这里**有什么**：一个按钮、一段文字、一个输入框 | 这里有一个按钮，上面写着「快速检索」 |
| CSS | 它**长什么样**：颜色、大小、圆角、摆在哪 | 圆角、细边框、浅纸色底，鼠标移上去字变深 |
| JavaScript | 碰到它**会发生什么** | 点一下，弹出检索框 |

<Callout kind="analogy">

像一套房子。HTML 是毛坯：哪里是客厅、哪里有一扇门、门上有个开关。CSS 是装修：墙刷什么颜色、门多宽、开关摆在多高。JavaScript 是开关后面的电线：按下去，灯才会亮。没装修的房子照样能住，只是不好看；没接电线的开关，按了没反应。

</Callout>

## HTML：用标签说「这是什么」

HTML 是一份带标记的文本。每样东西用一对**标签**包起来，标签名说明它是什么：`<button>` 是按钮，`<main>` 是页面的主体，`<h1>` 是一级标题。下面是一份极简的网页（示意，不是门户的真实文件）：

```html
<!doctype html>
<html lang="zh-CN">
  <head>
    <title>Patra · 医学文献门户</title>
    <link rel="stylesheet" href="/style.css">
  </head>
  <body>
    <header>
      <button type="button">快速检索</button>
    </header>
    <main>
      <h1>……</h1>
    </main>
    <script src="/app.js"></script>
  </body>
</html>
```

几个要点：

- 标签可以套标签：`<body>` 里有 `<header>`，`<header>` 里有 `<button>`。
- `<head>` 里放给浏览器看的信息（标题、要加载哪个样式文件），`<body>` 里才是页面上看得见的东西。
- `<link>` 指向 CSS 文件，`<script>` 指向 JavaScript 文件。HTML 自己不写样式和行为，只说「还要去拿这两个文件」。

门户的代码不是直接写 `.html` 文件，而是写在 `.tsx` 文件里，用一种长得很像 HTML 的写法。服务器先把它变成真正的 HTML，再发给浏览器。所以浏览器收到的仍然是 HTML。门户每一页最外层的骨架写在这里：

```tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html
      lang="zh-CN"

      data-scroll-behavior="smooth"
      className={cn(inter.variable, newsreader.variable, plexMono.variable)}
    >
      <body>
        {/* 「回到页首」锚点：放在文档最顶、不吸顶的元素上（挂在吸顶导航上时浏览器按其吸住的位置计算，只滚动一小段） */}
        <div id="top" aria-hidden />
```

现在不用看懂每一行，只认出熟悉的部分：`<html lang="zh-CN">` 说这一页是简体中文，`<body>` 里放页面内容，`{children}` 的位置会填进具体哪一页（首页、文献页……）。

## 同一个按钮，一层层叠上去

门户顶栏的「快速检索」按钮，三层都写在同一个标签上：

```tsx
            <button
              type="button"
              onClick={openSearch}
              onPointerEnter={preloadQuickSearch}
              onFocus={preloadQuickSearch}
              className="group/qs inline-flex h-9 items-center gap-2 rounded-full border border-border-default bg-paper-50 pr-1.5 pl-3 text-sm text-fg-2 transition hover:border-border-hover hover:text-ink-900 max-[880px]:size-9 max-[880px]:justify-center max-[880px]:p-0"
            >
              <Search className="size-3.5 shrink-0" strokeWidth={1.75} aria-hidden />
              <span className="max-[880px]:sr-only">快速检索</span>
```

- `<button>` 和里面的「快速检索」四个字是 HTML：这里有个按钮。
- `className="…"` 那一长串是 CSS 的简写（门户用一种叫 Tailwind 的写法，每个词是一条小样式规则，例如 `rounded-full` 是两头圆）。样式怎么写，在「样式：CSS 布局与 Tailwind」一篇里讲。
- `onClick={openSearch}` 是 JavaScript：被点的时候，执行一段叫 `openSearch` 的代码。

## 为什么要分成三层

分开写，改一样不牵动另外两样：

- 设计换配色，只动 CSS，按钮还是那个按钮，点了照样弹框。
- 检索框换一种打开方式，只动 JavaScript，按钮的样子不变。
- 另一方面，HTML 写清「这是按钮」「这是标题」，读屏软件（帮视障读者朗读网页的工具）和搜索引擎也看得懂这一页。按钮上那个 `<span>` 在窄屏时被 CSS 藏起来，读屏软件照样能念出「快速检索」，就是这个原因。
