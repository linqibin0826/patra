# 教学写法

学习站是静态页面，没有人在旁边辅导。对话里的辅导做法（先摸清读者在哪、一次只推一步、让读者先猜、讲完让他复述）要写进页面结构：读者翻到哪里、先看到什么、要点哪一下才看到答案，都由条目决定。

目标是读者读完能自己答出这个问题，下一次碰到类似的也能答，不是读过一段好的讲解。

## 每篇的骨架

1. **开头诊断题**（`Diagnose`，正文第一块，README 第 1 节）：一道凭直觉就能作答的单选判断或预测题，答案能看出读者缺不缺前置。必填 `options`、`answer`、`ifRight`、`ifWrong`，不能写子内容；有前置时用 `suggest` 指定推荐哪一篇（须在 `prerequisites` 里）。
   - 好：「同一台机器上 curl 通、Java 程序拿到空 503。问题更可能出在目标服务，还是请求走的路？」
   - 坏：「你了解 HTTP 代理吗？」（读者只能答是或否，看不出缺什么）
   - 所有带 `answer` 的题（诊断、小测、「你猜」）：正确项的位置每题轮换，不要总放 B；正确项和干扰项写得一样长、一样具体，解释放进 `ifRight` / `explain`，干扰项写读者真会有的误解。
2. **一节一步**：每节只推进一个想法，节标题写成那一步的结论或问题。段落短，一段一个意思。
3. **先猜后看**：在读者最可能猜错的地方放「你猜会怎样」，每篇 1～3 处，答案不能紧挨在题目下面直接可见。按位置选组件：
   - 流程里某一步前：`Stepper` 的 `guesses`（第 7 节）
   - 拖参数前：`Params` 的 `guess`（第 8 节）
   - 讲完一个机制后的小测：`Quiz`（第 3 节），一篇最多一两处
   - 排查的每个假设：`DebugTrail` 先读假设、再点开结果（第 11 节）
4. **配图**：内容有结构时才配图，一张图只讲一个关系；道理写在文字里，图只承载结构。纯步骤、命令、名词解释不配图。按结构选组件：
   - 部件之间的关系、一条消息怎么走：`Structure`（第 4 节）
   - 一次请求经过谁、时间花在哪：`Sequence`（第 5 节）
   - 一个东西的生命周期：`StateMachine`（第 6 节）
   - 几种做法并排比、出意外才看出差别：`Compare`（第 9 节）
   - 决策的几个选项：`DecisionOptions`（第 12 节）
5. **逐步动画**（`Stepper`，第 7 节）：一步一个变化，读者点「下一步」才往前走；在会猜错的那一步之前插「你猜」。不做从头播到尾的整段动画——那等于把答案直接递过去。查问题的经过不做成动画，用 `DebugTrail`。
6. **滑块与开关**（`Params`，第 8 节）：用在「参数变了结果怎么变」，先用 `guess` 问读者预测，再让他拖。
7. **强调块**（`Callout`，第 10 节）：只放一两段要强调的话，不把整节塞进去。
   - `lead`：概念篇的一句话定义；排查篇用 `label="结论先说"`；坑篇用 `label="坑在哪"`；决策篇用 `label="选了什么"`
   - `analogy` 打比方，`insight` 顺带想通的（坑篇的「怎么认出它」），`warn` 容易出错处，`cost` 决策的代价
8. **结尾**（正文最后一块，第 2 节）：一道迁移题 `Transfer`（换个场景还成立吗、换个参数会怎样），或一道复述题 `Recap`（用自己的话说出 X 为什么会 Y）；能出迁移题就出迁移题。两者都必填 `points`（参考要点，2～5 条）。下一篇由路线页给出，正文不写。

## 按难度调

- **入门**：不假设任何后端经验。先用日常例子，术语第一次出现当场解释；每节只引入一个新词。
- **基础**：可以假设读者写过简单接口，术语链到概念篇，不重复解释。
- **进阶 / 实战**：可以直接给代码、日志、配置；把篇幅花在「为什么会这样」和「怎么查到的」上。

## 语气

平实、直接。难的地方直说「这里大多数人会卡住」，不说「很简单」。不用 emoji，不喊口号，不夸读者。读者是有能力的成年人。

## 常见错误

| 错误 | 改成 |
|---|---|
| 诊断题问「你知道 X 吗」 | 问一个要用到 X 才能答对的判断题 |
| 一开头就是三段讲解 | 先诊断题，再一节一步 |
| 「你猜」的答案就在下一行 | 答案折起来，或放到「下一步」之后 |
| 每节都配一张图 | 只给有结构的内容配图 |
| 排查经过做成 `Stepper` 或时序图 | 用 `DebugTrail`，一步一个假设，被排除的也写 |
| 一张图同时讲调用链、数据流和状态 | 拆成几张，一张一个关系 |
| 整个机制做成一段自动播放的动画 | 拆成几步，读者点着走，中间插「你猜」 |
| 结尾是要点总结 | 换成迁移题或复述题 |
